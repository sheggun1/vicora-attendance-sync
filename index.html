A12 LAN diagnostics

Connect the A12 and this PC to the same router. Enter the device IP shown in its network menu. This test checks reachability only; it does not send commands or modify the device.

Port 4370 is a common biometric-terminal port, not a confirmed A12 protocol. Test results only identify reachable ports. Do not assume that a reachable port allows attendance-log retrieval.

Connection guide

  1. Find the router's LAN address and subnet.
  2. Set the A12 to a free IP in that subnet (or use DHCP if supported).
  3. Set the gateway to your router IP and subnet mask appropriately.
  4. Connect the A12 by Ethernet to the router.
  5. Run the diagnostic above from this PC on the same network.

We will only implement direct attendance sync after we identify the A12's supported communication protocol or SDK. USB import remains the working fallback.
